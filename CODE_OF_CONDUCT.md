# Code of conduct

Be respectful. Disagree with ideas, not people. No harassment, personal attacks, or discriminatory language, in issues, pull
requests, or any space tied to this project.

Maintainers may edit or remove contributions that break these rules and may block repeat offenders.
Report problems privately through a [security advisory](https://github.com/enderdev01/agent-notch/security/advisories/new)
or by contacting the maintainer through their GitHub profile.

This is a short adaptation of the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
