# Agent instructions

## Commands
- `node scripts/control.mjs doctor`: check the environment.
- `node scripts/control.mjs verify`: strings, shell syntax, swift build, swift test, Worker tests.
- `node scripts/control.mjs --help`: feature commands (app, event, state, vercel, hook, install...).

## Branches
Work only on `feat/`, `fix/` or `hotfix/` branches. Never commit or push to `main`.

## Commits
Conventional commits. No AI attribution trailers (`Co-Authored-By`, "Generated with").
